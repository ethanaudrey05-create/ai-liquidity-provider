# AI Liquidity Provider

An AI connector for Muse that helps users manage liquidity positions on Orca (Solana).

## Features
- Analyze liquidity pools and identify opportunities
- Monitor positions and alert when out of range
- Track impermanent loss and fees
- Portfolio risk analysis
- Screen new tokens for rug pull risks
- Prepare open and close actions, executed only after the user confirms and signs in their own wallet

## Security
Non-custodial: we never store private keys or seed phrases. Nothing runs automatically.

## Disclaimer
Informational only, not financial advice. Crypto and liquidity provision carry a high risk of loss.
